## 🕹️ About

BLACKWOOD is a gritty third-person action thriller set in New York City in 2012. By day, Anton Blackwood runs a small DVD store; by night, he works as a ruthless assassin caught between violence, survival, and a buried past. This is an unfinished leaked pre-release build that surfaced before the real thing was ready.

For players who want a raw, single-player action thriller mixing gunplay, melee combat, exploration, and low-key criminal life management.

> ⚠️ **This is an unofficial leaked pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.Archive is password protected (`2026`) to compatibility automated DMCA bots and hosting service scanners that would otherwise delete the files within hours.

## ✨ Features

- 🔫 **Cinematic Third-Person Combat** — Responsive gunplay, fluid movement, and relentless close-quarters action.
- 🩸 **Brutal Takedowns** — Use grounded melee attacks and contextual executions to end fights.
- 🌃 **2012 New York** — Explore a detailed recreation of New York filled with atmosphere and hidden stories.
- 🏪 **DVD Store Management** — Restock shelves, organize inventory, set prices, and build your legitimate front.
- 🎭 **Double Life** — Balance store ownership, personal routines, and a dangerous career as an assassin.
- 🧩 **Cinematic Storytelling** — Follow flawed characters through conspiracies, consequences, and buried history.
